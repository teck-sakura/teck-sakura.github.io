佐賀県出身 19歳 佐藤愛桜です🌸




先日、武元唯衣さんが卒業を発表されました。





卒業されるのが寂しくて





もっと一緒に活動したいという思いが強くて





「四期生としてこれからも一緒に活動しませんか？」と言ってしまったことがあります




変なこと言ってしまった…と焦っていると
「それは30代になってしまうわ！」と笑顔で
ツッコミを入れてくださって




どんな時も、その場を明るく笑顔で包み込んで下さる武元さんは、たんぽぽみたいに温かく優しい方だと改めて感じました。





とてもかっこいいパフォーマンスをされていて、バラエティーでも活躍されている姿を見て、毎回「すごいなぁ‼︎」と尊敬でしかなくて。
私も武元さんのようにオールマイティにこなせる人で在りたいとずっと思っていました。




武元さんと過ごせる残りの期間、少しでも多くのことを学ばせて頂けたらと思います。







サクラミーツに電話出演させて頂いた時に話していた、ツーショットのお写真です‼︎

武元さん、一緒にお写真撮った事忘れないで下さいね！！！笑


🦀

皆さんは、いかがでしたか？
楽しんで頂けましたか⁇




そして、今思い出しても恥ずかしくて、申し訳ない気持ちでいっぱいになってしまう、全員リレーがありました( ; ; )



早く走りたいという気持ちが先走ってしまい、身体が思うように動かず、転んでしまいました…。




あんな大事な場面で転んでしまうなんで、本当に悔しくて、申し訳なかったです…。




私が転んでしまった時に、沢山応援してくださりありがとうございました( ; ; )
皆さんの応援があったから、最後まで走ることができたと思います



先輩方や同期の皆んなも「大丈夫？」と声をかけて下さり、「そういう時もあるよ！」と沢山励ましてくださりました( ; ; )
