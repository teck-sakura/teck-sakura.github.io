‪‪受け取ってくれますか‬

Ui Yamakawa









また会いましたね💌

本日二度目ましてのやまかわういです







だいぶ出遅れちゃったかな

でもせっかくなので








ハッピーバレンタイン！💌




（猫、かわいい。な出来事があった日のわたしを添えて）










今日はひなにチョコをもらいました💌
（たぶん本命だと思う）

熊のチョコ🐻
ひならしくてきゅんとした〜
お返ししなきゃ



ひなとはこの前一緒に雪だるま作りました

雪だるま作ったあとはちゃんと冷えて
さむ〜って言いながら帰った

誘ってくれてありがとう❄️










ういちゃんはバレンタイン何食べたい？って
聞いてくれた方がいたので

バレンタインに食べたもののお話をすこし







数日前に、カフェにバレンタイン限定のメニューを食べにいきました🍨





可愛すぎる、、、

頭にちょこんとリボンが乗ってるところも
すこし左右非対称なお顔も
だいぶ垂れ耳なところも

あまりにも愛おしくないですか…？（ ; ; ）
涙が出るかと思った


可愛すぎて食べるのが心苦しかったけど、
大事にすこしずつ食べ進めて

最後にリボンのところを食べました
🎀


お察しの通り、
いちばん好きなものを最後に残す派のひとです







別の日には、買い物をしていたら
通りかかったお店にバレンタインコーナーがあって

自分へのバレンタインに
惑星のチョコを買ってみました🪐


はじめて自分にチョコ買ったな🫢💭

誰かに渡すのも素敵だけど、
自分のために買うっていうのもいいものですね

うれしくてうきうきで帰りました







そしてなぜか誰に渡す訳でもなく
バレンタインのメッセージカードまで買っちゃった

すごく可愛かったからつい、、、


でも今日でバレンタイン終わっちゃうから
飾るわけにもいかないし


どうしようかな、


うーん、、、













受け取ってくれますか…？























ほんとは渡したくて買った

🤫











2月のイベントといえば、
先週は節分もありましたね( ¨̮ )

夜ご飯にはちゃんと恵方巻きを食べました


その前には
ちゃんと「節分 方角 2026」って調べて

ちゃんと「南南東」ってどっちってなって

それでもなんとか探し当てて

ちゃんと…

…おそらく「南南東」のほうを向いて食べました
（多分いちばん大事なところ）



でもちゃんと黙って食べたから
来年の節分まで幸せに過ごせますように⊹ ࣪ ˖







考えてみれば、
その瞬間たくさんの人の願いが向く方向が
一致するのって
なんとなく不思議なことだなあと

だからこそ
願う気持ちが幸せを形にするくらい
大きな力を持つのかな〜


たくさんの人が願うほど、
あつまった願いの強さが力になって

魔法みたいに幸せを運んでくれるのかもね


わたしの願いも、
みなさんに幸せを運ぶ魔法を
ほんの少しでも手助けできていますように




˚‧︵‿☆






思えば、恵方巻きを1人で食べるのは
今年がはじめてのことで

食べ始める前の
あのなんとも言えない緊張感は

1人の食卓では味わえないのだと知りました



「食べ終わるまで喋っちゃいけない」なんて
1人じゃつい喋っちゃうことのほうが難しいもんね


「黙って食べる」ということを
特別に思える食卓の幸せを身に沁みて感じました





みなさんは恵方巻き食べたかな


1人で食べたよってひとは
わたしと一緒に食べたことにしましょう( ¨̮ )

食べてないよってひとは
わたしがみなさんの分まで幸せ願ったので安心してください( ¨̮ )



一緒に幸せな1年にしようね🍊









ーー୨୧ーー

みなさんの毎日に
食べ物とか動物とか好きなものとか

あなたのことを癒してくれる何かが
一つでも多くありますように











またね🌸
