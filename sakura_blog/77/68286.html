‪‪乙女座満月の夜‬

Ui Yamakawa









こんにちは🍊



ブログを開いてくださりありがとうございます⊹ ࣪ ˖




宮城県出身20歳
四期生の山川宇衣（やまかわうい）です
　








感覚としては
ついこの間雪が降ったばかりなのだけど

最近ますます春のことを考える日が増えてきました🌸







そんな中、これは先週のこと

この冬から愛用していた電気毛布の電源が突然つかなくなるという悲しい出来事が、、、（ ; ; ）






もうあったかくなるからってことかな、、

春が来るのを見計らったようにお別れのときがきてしまいました🥲🌸






わたしにとってはまだちょっと寒いのだけどな…🥲とも思いつつ

これを機に、そろそろ気持ちも本格的に春を迎える準備に取りかかろうと思います💭








なんて、
まだ春を迎えていないつもりで話しているけど

3月になったということは、もう十分季節は春って言われる頃なのかな…？



でも、まだ寒い日もあるから
ギリギリ冬と言っていい気もするような…






うーん、
なんだかどっちつかずな時期ですね








でも考えようによっては、


春が好きだったら「もう春」って言えて
冬が好きだったら「まだ冬」って言える


余白のある時期ってことですね🍊





季節を確信するまでは、
いまを自分のすきな季節にして

自分に都合よく生きてみたりね( ¨̮ )








みなさんは春と冬どっちを選びますか？
🌸❄️






ちなみにわたしはもう、
春を通り越して夏を見てますよ🍉


今年の夏もたくさんスイカたべよっと






とは言え、春だなあって瞬間を感じたらきっと
春好きーーってなるんだろうな



秋は美味しいものにたくさん目移りするし

なんだかんだ、やっぱり冬も素敵ってなるし



夏が好きと言いつつ、年中いろんな季節に浮気してます…😖





でもでも、やっぱり夏がいちばんなことに変わりはないから

特別だよってちゃんと伝えよう💭








\夏がいちばんすきだーー/





お、これは『光源』のMVのわたしですね






それではここからは
四期生楽曲『光源』のお話を…💌











ーー୨୧ーー











四期生楽曲『光源』

Music Videoは観ていただけましたか？🌸







それぞれが抱える感情や葛藤が見え隠れする映像の中で、わたしは



誰とも本音で話せずに
上手に関係を築けないでいる


自分をその状況に置いているのは自分自身で
そんな自分に腹が立つ



人間関係に悩み、自分自身に憤りを感じているというキャラクターをいただきました。









言葉自体が持つ意味以上に、そこに勝手に相手の意図を汲んで

勝手にそれを受け取ってしまうような、




自分が口にした言葉を、自分が思う以上の意味で相手に受け取られてしまうのではないかと

勝手な妄想に囚われて後悔を繰り返すような、




人間関係を築くのがきっと人一倍下手な自分とそのキャラクターが重なって

わたしはMVの中の自分に、自分自身を見ていました。













“孤独の影　怯えながら生きてる

人間（ひと）は誰もみんな”











この世界に自分はひとりぼっちだと感じることが”孤独”なのだとすれば


その世界に唯一存在する”自分”すらも味方でないという孤独は計り知れないもので







自分を信じること、認めることは自分の自由で
その判断は自分に委ねられているのだから



自分の味方をするもしないも自分次第で、
その上で

自分を孤独にしているのは
他でもない自分自身なのかもしれない





そのことに気が付いたとき、
独りよがりで小さな世界に 微かに光が差す窓があることを知って


その窓の外に目を向けてみることで
ようやく孤独で窮屈な世界から一歩踏み出せるような



それと一緒に、ひたすら内に向けていた感情が
自分の外側へ溶け出していくような感覚がきっとあるはず






わたしはどんなときも、
抱えた感情を外ではなく内に向けてしまう人間なので

そんなとき、窓の外を眺めてみることを大事にしたいです

🍊








そして、











“あの宇宙が何かの可能性かもしれない

もっとこっちへおいでよと手招きする

新しい未来よ

僕らは地図を見つけた”












「宇宙」なんて
すこし大袈裟に聞こえるかもしれないけど、


計り知れない大きな力が自分を掬い上げてくれるかもしれない


そんな感覚に身を委ねることで乗り越えられる夜があるなら


この曲がたくさんの方に届けばいいと心から思います🌸










MVでは「帰り道」をテーマに、
一人ひとりが抱えるものと小さく大きく戦いながら


それでも光を求めてもがくみんなの表情や感情の変化にも注目しつつ

たくさん観てくださると嬉しいです⊹ ࣪ ˖



よろしくお願いします！🌸



















🐣と🐻





昨日はたちの誕生日を迎えたひなまるさん
さすが熊がよく似合いますね🐻💌



またみんなのいい写真撮れたらお裾分けするね୨୧











そうだ、「ひな」と言えば…💭



今年のひな祭りの日は
どうやら乙女座満月と皆既月食が重なる夜だったとか。




「乙女座満月」

はじめて聞いたこの言葉に
乙女座のわたしは縁を感じずにはいられないわけで…🌙




すこし調べてみたところ、


まず乙女座は、秩序と分析、整理整頓（🫢）という意味合いを持つ星座で

満月は「物事が満ち、振り返りと調整を行うタイミング」とのこと。


そしてそこに皆既月食が重なることでその意味合いはいっそう強まり、

「物事が満ち切り、何かしらの方向転換を強いられる」といった意味合いになるのだとか。





当日はあいにくの雨だったけど、
きっと雲の上には綺麗な月が輝いていたんだろうな〜




孤独に怯える少年が
見上げた先に未来への地図を見つけた夜空には


わたしたちのことを見守ってくれるお月様がいるみたいなので


きっと何があっても大丈夫ですね🌙







そしてみなさんが
わたしたちのことを見守ってくださるように


わたしたちも
いつでもみなさんのことを見守っています😉


お互いがお互いの光源になれたら素敵だね🌸





なんてことを、
乙女座満月の夜にひとりで考えていました🌙





いい夜になったな

ありがとう乙女座満月( ¨̮ )

☾ ⋆⁺₊⋆ 












ーー୨୧ーー











最後に、
MVにまつわる思い出をひとつ🍊





『光源』のMVを撮影した日、

ほんとうに久しぶりに 全力で走って転んで膝を擦りむきました

（1サビのところ🤧）





そのときの痛みって、いつからか

子どもの頃の自分がちょっぴり大袈裟に感じていたものなのかと思っていたけれど




「注射なんか膝擦りむくより痛くないよ」ってあれ

都合のいい決まり文句なんかじゃなかったですね…



疑ってごめんなさい🥲






でも、ちょっぴり血が滲む膝に
こんなのいつぶりだろうって思わず笑えてくるような


いい日だったなあ







やっぱり子どもの頃って、


今となっては些細な悩みに
世界の終わりを思うくらいに取り憑かれたり



そんなことでって笑う大人の気持ちが
ようやく分かるようになったのはきっと最近のことで

あの頃の自分の小さな心と身体で抱えるには
すこし大きすぎた不安だったり



それらと向き合う時間も含めて

輝いていたあの頃の尊さを突きつけられるような感覚がありました。





いまでは膝擦りむいたくらいじゃ

涙より先に笑いが込み上げるくらいには成長したんだなあと思うと



自分の成長と、もうあの頃には戻れないという
すこし寂しいその事実に



嬉しいような、ちょっぴり焦りを感じるような…





この感情は、「喜び」なのか「不安」なのか、


いまでも言いようのない感情に揺られて
どこかにその答えを探している自分に


なんだ、
まだまだ子どもじゃんって思わされるような


なんだか色々な気持ちにさせてくれた経験でした💭





その日からしばらく経って、
今ではもう傷跡も綺麗になくなったことだし


たまには転んで
擦り傷つくってみるもんですね( ¨̮ )


人生の教訓にしよっと🍊








とは言いつつも、
けがはしないに越したことないのだけどね…🤧





ちょっぴり話は逸れますが、、



わたしは物との距離感を掴むのが下手で

いっつも色んなところに身体をぶつけてしまうことが悩みのひとつでもあるので


わたしにとって打撲は大敵なのです…





パン屋さんでアルバイトをしていた頃、


パンが並ぶ段々になった棚を掃除する度に

上の段との距離が掴めずに頭をぶつけていたことが思い出されます🥲


お客さんいると恥ずかしいんだよなあ、、



不意の打撲がいちばん響いたりするので

みなさんもできるだけ身の回りには気をつけてくださいね🥲











それではこの辺りで今日の一枚…

と言いたいところですが



前回も今回も
「宇宙」や「月」といったワードが出てきたことですし


今日は久しぶりにこちらのコーナーを( ¨̮ )










🌙ういの気まぐれ占い







余裕のあるひとは足元に加えて

頭の周りにも気を配ってあげると運気がアップするはずです😖🍊

いい一日になりますように！











長くなりましたが、ここまで読んでくださったみなさんにうれしいお知らせを💌





本日19時57分〜
NHK総合「うたコン」に出演させていただきます！！✨

今夜は「うたコンの夜」ですね🌙


素敵な夜にしましょう〜！ぜひご覧ください✨













またね🌙
